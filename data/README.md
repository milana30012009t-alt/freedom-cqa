# data/ — рабочие данные приложения (не попадают в Git)

- `datasets/<GROUP>.raw.json` — ответ API организаторов или загруженный файл, байт-в-байт (содержит подписанные ссылки на записи звонков).
- `datasets/meta.json` — активный набор, время загрузки, отчёт о проверке.
- `store/checklists.json` — все версии чек-листа (неизменяемые снимки) и номер активной.
- `store/evaluations/*.json` — оценки: результаты по критериям, доказательства, снимок чек-листа, решения проверяющих, история.
- `store/appeals.json` — апелляции с полной историей.
- `cache/audio/` — скачанные записи звонков.

Сбросить демо-состояние (оценки и апелляции) без удаления набора данных: `npm run reset`.
