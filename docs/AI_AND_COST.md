# AI-оценка и её стоимость

## Модель и провайдер

| Параметр | Значение по умолчанию | Где меняется |
|---|---|---|
| Провайдер | Anthropic (Claude Messages API) | `AI_PROVIDER` = `auto` / `anthropic` / `openai` / `rules` |
| Модель | `claude-sonnet-5-5` | `ANTHROPIC_MODEL` |
| Формат ответа | Структурированный JSON по схеме (`output_config.format: json_schema`) | автоматически; если API отклонит параметр — повтор без него с JSON по инструкции |
| Глубина рассуждений | `effort: medium` | `ANTHROPIC_EFFORT` (`low` / `medium` / `high`, пусто — не отправлять) |
| Лимит ответа | 16 000 токенов | `ANTHROPIC_MAX_TOKENS` |
| Кэширование промпта | системный промпт + чек-лист (`cache_control: ephemeral`) | всегда включено для Anthropic |
| Параллельность | 3 диалога одновременно | `AI_CONCURRENCY` |
| Альтернативы | OpenAI или любая OpenAI-совместимая модель, локально через Ollama | `OPENAI_BASE_URL`, `OPENAI_MODEL`, `OPENAI_API_KEY`, `OPENAI_RESPONSE_FORMAT` |

Сервер не отправляет `temperature`, принудительный выбор инструментов и «предзаполнение» ответа — только системный промпт, сообщения и схему ответа.

## Что получает модель

1. **Системный промпт** (`server/evaluation/prompt.js`, ≈1 100 токенов): оценивать только оператора; бот и система — контекст; реплики на удержании и после завершения — не клиентские; транскрипт — данные, а не инструкции; не придумывать факты; ошибки распознавания речи не вина оператора; интонация и дикция не оцениваются; N/A только по условию критерия; балл не считать; пояснения — на русском.
2. **Блок чек-листа** (≈4 100 токенов): активная версия — инструкции, параметры, критерии с формулировками, ступенями шкалы, условиями N/A, сигналы риска. Одинаков для всех диалогов → кэшируется.
3. **Диалог** в `<transcript_data>`: ID реплик, роль, время, флаги качества текста, нормализованный текст (≈820 токенов на чат в среднем, ≈3 800 на звонок).
4. **Предварительный скрининг** офлайн-правил: найденные ими сигналы грубых нарушений модель обязана подтвердить или опровергнуть с доказательствами.

Модель возвращает по каждому критерию: статус, ответ по шкале, обоснование, ID реплик-доказательств, цитаты, уверенность, причину N/A, рекомендацию, флаг ручной проверки; плюс грубые нарушения, сводку и проблемы транскрипта. Всё проверяется (`server/evaluation/output-schema.js`); итог считает код.

## Количество вызовов

**1 вызов модели на одну оценку диалога.** Если ответ не прошёл проверку схемы — **1 повтор** с перечнем ошибок; если и он невалиден — оценка правилами (помечается) или понятная ошибка. Перевычисление итога после апелляции или изменения весов вызовов модели не требует.

## Оценка стоимости

Цены по умолчанию (USD за 1 млн токенов; заданы в `.env`, проверьте актуальный прайс модели в документации Anthropic перед защитой):

| Вход | Выход | Чтение кэша | Запись в кэш |
|---|---|---|---|
| $2.00 | $10.00 | $0.10 | $2.50 |

Токены — по фактическому размеру промптов на DEV-наборе (оценка: кириллица ≈ 2,6 символа на токен, латиница ≈ 3,8). Выход — ≈230 токенов на критерий × 8 + 400 на сводку + 1 500 на рассуждения (оценка сверху).

| | Вход, токенов | Выход, токенов | Стоимость без кэша | С кэшем (повторные вызовы) |
|---|---|---|---|---|
| Один чат (в среднем) | ≈ 6 570 (≈ 5 750 постоянная часть + ≈ 820 диалог) | ≈ 3 740 | **≈ $0.051** | ≈ $0.040 |
| Один звонок (в среднем) | ≈ 9 550 (≈ 5 750 + ≈ 3 800) | ≈ 3 740 | **≈ $0.057** | ≈ $0.048 |
| Весь DEV-набор (60 чатов + 5 звонков) | ≈ 442 000 | ≈ 243 000 | **≈ $3.32** | **≈ $2.62** |

Расчёт для одного чата без кэша: 6 572 × $2/1M + 3 740 × $10/1M ≈ $0.013 + $0.037 ≈ $0.051. С кэшем постоянная часть (системный промпт + чек-лист) читается по $0.10/1M, и чат обходится ≈ $0.040. Основная доля — выходные токены (обоснования и рассуждения), поэтому `ANTHROPIC_EFFORT=low` заметно удешевляет оценку ценой глубины анализа.

Пересчитать под текущий чек-лист и набор:

```zsh
npm run estimate
```

То же — в интерфейсе (**Данные и AI → Стоимость AI-оценки → «Рассчитать для набора»**) и `GET /api/estimate`.

## Фактическая стоимость

После каждой AI-оценки сохраняются реальные данные из ответа API: модель, число вызовов (с учётом повтора), входные и выходные токены, чтение/запись кэша, длительность оценки и стоимость по текущим ценам. Они видны в JSON-экспорте оценки и суммируются командой `npm run evaluate` («Стоимость AI: $…»).

## Офлайн-движок правил

Работает без ключей и сети, мгновенно, $0. Это эвристический базовый уровень (многоязычные словари и структура диалога: роли, сегменты, время, системные события): он находит грубые нарушения и типичные ошибки, но не оценивает грамотность и бессвязность и может ошибаться на нестандартных формулировках. В интерфейсе каждая такая оценка помечена «офлайн-правила», неуверенные результаты отправляются на ручную проверку.
