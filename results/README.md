# Результаты (Results JSON 1.0)

- `dev/results.json` — 65 диалогов DEV. Создаётся командой `npm run export:dev`.
- `prod/results.json` — 10 контрольных чатов. Создаётся командой `npm run export:prod -- --group <ID>`.

Оба файла создаются только программой при подключённой модели и сразу проверяются. Не редактируйте их вручную:
итоговый балл и номера реплик сверяются с данными организаторов. Перед push запустите `npm run validate:results`.

`preview/` — прогон офлайн-правилами без модели. Папка в `.gitignore`, к сдаче не допускается.

Формат и порядок сдачи описаны в [docs/RESULTS.md](../docs/RESULTS.md).
